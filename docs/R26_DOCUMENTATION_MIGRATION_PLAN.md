## Inventory method and classification

Enumerated with `git ls-tree -r --name-only fd9855162f373b961f9774bbea054899aa0014be` and `git ls-files '*.md'`; inspected every Markdown document's purpose, headings, current/historical sections and relevant gate/contract content. Searched all tracked UTF-8 text (including source, tests, scripts and configuration) for filenames, inline-code/plain paths, Markdown destinations/fragments and asset directories. Binary evidence was inventoried by path and existing textual references; screenshots were not newly interpreted as live facts. No ignored/private output was read as documentation.

Primary classes: **A** current reference/navigation/procedure (not every A is governing analytical authority); **B** primarily historical evidence; **C** intertwined current/approved material and history. C does not demote approved requirements: MASTER_SPEC clauses remain governing regardless of their file's mixed classification. Historical tests prove behavior at their revision; they do not establish current capabilities or live semantics. Approved requirements, accepted implementation behavior, historical verification, superseded proposals and unresolved capabilities remain separate claims.

The inventory's **M/T** reference counts are frozen baseline discovery evidence: M = unique other Markdown files with a syntactically resolved link to this exact path; T = unique other tracked UTF-8 files containing its literal basename (includes M, inline code, plain text and test/source occurrences). Basenames such as `index.md` and the two original/archive name pairs are ambiguous in T; it is a search lead, not proof of a resolved edge. I/O lists show selected important inbound/outbound references, not every edge; `none` means no such Markdown target, not no semantic dependency. Fragment references and family asset paths are analyzed separately below. A Markdown-link check or Git rename label alone is never preservation evidence.

Each Markdown file has one primary disposition owner: KEEP (retain current path), DONE (R2.5 archive/compatibility, no work), or a proposed package ID. Package scopes below are exhaustive and disjoint for primary documents. Ordinary shared navigation edits to index/backlog/status and compatibility links are supporting changes, explicitly reviewed per PR rather than independent moves. Every asset likewise has a keep/hold/owner disposition. Proposed destinations are inline code, not claims that those paths exist today.
